# Puntos Checkpoint

Sistema de gestión de puntos de fidelización para Check Point Barbershop.

## Características

- Buscador en tiempo real por nombre o teléfono
- Registro de puntos por cliente
- Integración con Supabase
- Interfaz con identidad visual de Check Point
- Deploy en Vercel con costo $0

## Stack Técnico

- **Frontend:** Next.js + React
- **Base de datos:** Supabase
- **Hosting:** Vercel
- **Control de versiones:** GitHub
